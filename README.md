# Loom Launcher

This is a personal project to build a launcher application for Minecraft Java Edition using Rust and React. The main purpose of this project is to learn Rust
and explore new ways of building desktop UIs. I don't know yet if this is going to be an application to be released or just a quick thing to play around with Rust.

## Technologies

- Rust
- React 19
- Shadcn UI
- Tailwind CSS
- Tauri

## Getting Started

To get started with this project, clone the repository and follow the instructions below.

### Prerequisites

- Rust
- Cargo
- Bun

### Installation

1. Run `bun install` to install the project dependencies.
2. Run `bun tauri dev` to start the development server. This should trigger Cargo to install and build Rust dependencies.
